# Project 1: Olympics, Airports and Restaurant Vendors, pandas Basics

**Course:** TDM 102

## Overview
Introductory pandas work across three datasets: US airports, Olympic athlete records, and restaurant vendor data, covering loading, filtering, and basic value counts and bar charts.

## Techniques
- Loading CSVs with `pandas.read_csv`
- Boolean filtering across multiple conditions
- `value_counts()` for frequency counts
- Bar charts with `matplotlib`

## Key Finding
Found the top 5 countries by number of Olympic athlete entries and visualized the distribution of restaurant vendors by category.

## Data
- `airports.csv`, `athlete_events.csv`, `vendors.csv`: check file sizes before including, olympics and vendor files are usually small
