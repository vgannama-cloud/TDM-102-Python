# Project 7: Control Flow, Conditionals and Loops in Python

**Course:** TDM 102

## Overview
Practice with Python control flow: if/else logic (a lightsaber color to Jedi role example), a social media usage dataset classified with `numpy.where`, while loops, and a manual loop counting species in a Star Wars characters dataset.

## Techniques
- `if`/`elif`/`else` branching and dictionary lookups
- Vectorized conditional labeling with nested `numpy.where`
- `while` loops with incrementing and decrementing counters
- Manual row-by-row iteration with `.loc` for counting categories

## Key Finding
Classified social media users into usage/sleep categories using nested `numpy.where`, then used a manual while loop to count human versus non-human characters in a Star Wars dataset.

## Data
- `social_media.csv`, `characters.csv`: small, safe to include in `data/`
