# TDM 102, Data Mine Seminar Projects (Python)

Weekly data science projects completed as part of Purdue's Data Mine seminar (TDM 102), using Python for data analysis, statistical techniques, and applied data workflows.

## Projects

| # | Project | Dataset / Topic | Key Techniques | Link |
|---|---------|------------------|-----------------|------|
| 01 | Olympics, Airports and Restaurant Vendors | Airports, Olympic athletes, restaurant vendors | pandas basics, filtering, bar charts | [project-01](./project-01-olympics-vendors) |
| 02 | Rotten Tomatoes Movie Ratings | Rotten Tomatoes movies | Data cleaning, crosstab | [project-02](./project-02-rotten-tomatoes) |
| 03 | Video Games and Google Play Store | Video game sales, Play Store apps | groupby, string cleaning | [project-03](./project-03-videogames-playstore) |
| 04 | Titanic, Lists, Subsetting and Categoricals | Titanic passengers | Categoricals, subsetting, crosstab | [project-04](./project-04-titanic) |
| 05 | pandas vs Polars, Flight and Baseball Data | Flights, Lahman baseball | Benchmarking, polars regex selection | [project-05](./project-05-pandas-polars) |
| 06 | Flights and Ice Cream, Grouped Aggregation | Flights, ice cream ratings | groupby, qcut, cut binning | [project-06](./project-06-flights-icecream) |
| 07 | Control Flow, Conditionals and Loops | Social media usage, Star Wars characters | if/else, while loops, numpy.where | [project-07](./project-07-control-flow) |
| 08 | Taylor Swift and YouTube, Custom Functions | TS discography, YouTube channels | Custom functions, string cleaning | [project-08](./project-08-taylorswift-youtube) |

## Tech Stack

Python, pandas, numpy, polars, matplotlib, Jupyter

## About

Part of Purdue's [Data Mine](https://datamine.purdue.edu/) program, a data science learning community. Each notebook was completed individually as part of the weekly seminar curriculum.
